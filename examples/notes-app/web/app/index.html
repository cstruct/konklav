Sign in once at the login page and both this app and the admin page know you.

Notes

    Your access

    The admin page can change your roles or sign you out. This app's backend hears of it over Konklav's change feed within about a second.

    What DPoP stops

    The access token is in this page's memory, so a script injected into the page could read it. It's bound to a key the page can use but not export, so the token alone is worthless.
