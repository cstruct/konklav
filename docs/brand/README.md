# Brand

The mark is a rounded seal with a K cut out of it. The K's stem is a
keyhole: *conclave* comes from *cum clave*, "with a key", and *klav* is
Swedish for clef, from the same Latin *clavis*.

| File | Use |
| --- | --- |
| `konklav.svg` | Default mark, for light backgrounds |
| `konklav-dark.svg` | Mark for dark backgrounds |
| `konklav-mono.svg` | One colour, inherits `currentColor`; keyhole and arms are cut out |
| `konklav-wordmark.svg` | Mark and name, for light backgrounds |
| `konklav-wordmark-dark.svg` | Mark and name, for dark backgrounds |

The K's arms are cut out with a mask, so the page behind shows through them.
The wordmarks set the name in live text (Inter 600, falling back to Helvetica
Neue or Arial); outline it before using a wordmark where the font may be missing.
